# Mini Task Manager

Aplicación web sencilla para administrar tareas personales.

## Objetivo

Practicar desarrollo web y aprender a utilizar Git, GitHub y GitHub Desktop.

## Tecnologías

- HTML
- CSS
- JavaScript

## Funcionalidades

- Agregar tareas.
- Visualizar tareas.
- Marcar tareas como completadas.
- Eliminar tareas.
